# Twitch Redesign — Usability Study

## What it was

A usability evaluation of the redesigned Twitch mobile interface against the original, testing whether the redesign improved navigation, content discovery, and accessibility.

- **Participants:** 6, aged 23–33. Familiar with Twitch but not regular users — they'd used it once or twice.
- **Setup:** remote, over Zoom. Participants used their own phones (Android or iOS) and shared their screens.
- **Design:** within-subjects — everyone tried both the original and the redesigned interface.

## Tasks (same on both versions)

1. Find and select a followed live stream.
2. Find the stream recommendation feature.
3. Change the app language, starting from the Settings page.

## Results

- Participants completed tasks faster and more successfully on the redesigned interface overall.
- **The language task failed on the original interface** — the app had no language option at all, so it was assigned a 240-second completion time. The redesign adds a language switch in Settings.
- Other changes in the redesign: the redundant "Live Channels" section was removed from Browse; clips were removed from the Category page and replaced with stream recommendations; Stream Manager was moved into the Creator Dashboard.

## Clearest finding

The language task: users who don't read the app's default language had no way in — a multilingual / language-barrier issue. The fix is a language setting users can actually reach.

*Source: Mbah_Joshua_Report.pdf, "Improving Usability from the Livestream Viewing Experience: A Usability Evaluation of an Enhanced Twitch Interface."*
