# Twitch Redesign

A UI redesign of the Twitch mobile app, focused on making live streams easier to find and follow.

## What it covers

Wireframes for the four main screens:

- **Home** — live streams from followed channels
- **Browse** — all categories, searchable
- **Category** — live streams within a selected category
- **Settings** — account settings

Bottom navigation across the app: Home, Browse, Go Live, Activity, Profile.

## Files

- `Mbah_Joshua_Wireframe.pdf` — the full wireframe set (4 pages)

Designed in Figma, informed by a usability study with 2 participants.
